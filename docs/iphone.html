iPhone guide

Life is a web app, so on iPhone you install it from Safari. Everything below also lives in Settings → Use it on your iPhone, with the exact values to copy.

You need Life reachable over HTTPS from your phone, for example with Tailscale (see Set up). iOS only allows notifications and Face ID for HTTPS sites.

1 · Install it

  1. Open your Life address in Safari and sign in.
  2. Tap Share → Add to Home Screen, then open Life from the new icon. It runs full screen, with its own launch screen.

2 · Notifications

  1. In the installed app: Settings → Phone notifications → Turn on for this device, and allow notifications.
  2. Tap Send a test. Choose what to hear about (reminders, morning brief, trips, expiries, problems).

3 · Face ID

  1. Settings → Face ID → Set up Face ID on this device. The key stays in your iPhone's Keychain.
  2. Switch on Only open Life with Face ID and pick when it locks again.

Keep a way back in: once Face ID is required, the password works only from the computer Life runs on.

4 · Share into Life (Instagram, links, screenshots)

  1. Settings → Use it on your iPhone → Set up the "Save to Life" Shortcut. It creates a token and shows the values.
  2. In the Shortcuts app: + → name it Save to Life → ⓘ → Show in Share Sheet (URLs, Text, Images).
  3. Add Get Contents of URL: URL as shown, method POST, header Authorization = the value shown, Request Body Form: text = Shortcut Input (and images = Shortcut Input to share screenshots).
  4. Add Get Dictionary Value (key message) then Show Notification.
  5. In Instagram: paper plane → Share to… → Save to Life. Tap Test this token in Life if anything is off.

Tip: if Instagram hides a caption, Life still reads the slides. If nothing can be read it goes to your Inbox.

5 · Calendar

Settings → Use it on your iPhone → Create my calendar link → Subscribe in Calendar. Tasks with dates, events, reminders, trips, birthdays and passport/visa expiries appear and stay up to date. Reset link cuts off an old link.

6 · Siri: "what's my day?"

  1. Shortcuts → + → Get Contents of URL (the link under step 5 in Settings) → Speak Text.
  2. Name it What's my day and say it to Siri, or add it as a Lock Screen or Home Screen widget.

What iOS does not allow

A web app cannot have native Home Screen widgets or appear in Siri without a Shortcut. The Calendar feed and the Shortcuts above are the closest equivalents.
