Set up

About 10 minutes for the basics; the phone and integrations are optional extras you can add any time. Life runs on your own computer (or a small server you control); your phone just opens it.

What you need

  • A computer that is on when you want Life: Windows, Mac or Linux. A home PC works well.
  • A recent Python 3 (developed and tested on 3.14). Get it from python.org; on Windows tick "Add Python to PATH".
  • Git to download and update the code (or download the folder as a zip).
  • For the phone: an iPhone with Safari, and Tailscale (free) on the computer and the phone, so the phone can reach it privately over HTTPS.
  • Optional: Node.js 18+ (only to run the JavaScript tests).

1 · Get the code and start it

  1. Download the project: git clone <your repository address> life, then open the life folder.
  2. Windows: double-click run.bat. Mac/Linux: run ./run.sh. The first run creates a private Python environment, installs the requirements (a few minutes) and starts the server.
  3. Open http://127.0.0.1:5055 in a browser on the same computer. Choose a password (8 or more characters; use a long one). That is your account: there is no sign-up and no cloud.
  4. Settings → You: your name, timezone, currency, passport country and where you live. (These drive the visa and entry-rule features.)

Everything you save lives in one folder, data/, next to the code. It is never uploaded anywhere by Life.

2 · Keep it running

Life stops when you close its window, so for daily use run it in the background:

  • Windows: NSSM (a service wrapper): program .venv\Scripts\python.exe, arguments app.py, start directory = the project folder. Or a Task Scheduler task "At log on" that runs .venv\Scripts\pythonw.exe app.py in the project folder (no window).
  • Mac: a launchd agent; Linux: a systemd service running .venv/bin/python app.py in the project folder.
  • Keep the computer awake (power settings) if you want reminders and notifications at any hour.

3 · Reach it from your iPhone

iOS only allows notifications, Face ID and installation for HTTPS sites, so Life needs a secure address your phone can reach. The easiest private way is Tailscale: only your own devices can open it.

  1. Install Tailscale on the computer and on the iPhone, and sign in to the same account on both.
  2. On the computer, in a terminal: tailscale serve --bg 5055. Tailscale prints an address like https://your-pc.your-tailnet.ts.net with a real certificate. Do not use tailscale funnel: that makes it public.
  3. In the project folder create a file named .env with one line: LIFE_HTTPS=1, then restart Life. (This marks the sign-in cookie as Secure.)
  4. On the iPhone, open that address in Safari and sign in. Then follow the iPhone guide: add it to the Home Screen, turn on notifications, Face ID, sharing, Calendar and Siri.

Prefer not to keep a computer on? A small cloud server works too: run Life there behind Caddy (it fetches a certificate automatically) with a long password. Details are in SETUP-PHONE.md in the project folder. Never expose the development server to the internet.

4 · Add integrations (all optional)

Open Settings, paste the key, done. Keys are stored encrypted and take effect immediately (no restart). A value in .env is still honoured as a fallback; what you type in Settings wins. Each integration reports its health in Settings → Data health.

5 · Your visas and entry rules

Set your passport country and where you live in Settings → You. Add each visa you hold in Travel → Documents & visas (type Visa, with the country and expiry). Open any country in Travel to see Entry for you, or the Where can I go? tab and press Check every country (about 5 minutes in the background; cached for a week).

Configuration reference

Most settings live in the app. These environment variables (in .env or the system environment) are for the server itself:

VariableMeaning
LIFE_PORT / LIFE_HOSTPort (default 5055) and bind address (default 127.0.0.1: only this computer; Tailscale forwards to it)
LIFE_HTTPS=1Serve cookies as Secure and send HSTS (set it when you use the HTTPS address)
LIFE_DATAWhere the data folder lives (default ./data)
LIFE_FERNET_KEY, LIFE_SECRETSupply your own encryption / session keys instead of the generated files in data/
LIFE_AI_MOCK=1Use a built-in fake model (for trying things without any key, and for tests)

Backups, restore, updates

  • Automatic: a nightly copy of the database in data/backups (14 days kept).
  • From your phone: Settings → Your data → Download a backup (saves to the Files app). Backup with key also includes the encryption key; keep that file private (for example in iCloud Drive).
  • Back up data/fernet.key too. It encrypts passport numbers, health values, scans and the keys you entered. Without it those are unreadable, by design.
  • Restore: stop Life, copy the chosen life-….db over data/life.db (and put your fernet.key back), start Life.
  • Update: stop Life, git pull, start it again. Your data is untouched. Run the tests if you like (below).

Troubleshooting

ProblemTry this
Phone can't open the addressIs Tailscale connected on the phone and the computer? Does the address work in a browser on the computer? Is Life running? Did you use the full https://…ts.net address (with the port if you chose one)?
No notifications on iPhoneIt must be the installed app (Home Screen icon), opened over HTTPS, with notifications allowed in iOS Settings → Notifications → Life. Then Settings → Phone notifications → Turn on → Send a test.
No Face ID optionOpen the HTTPS address (passkeys need it) and set it up on the iPhone itself: Settings → Face ID.
Locked out after requiring Face IDOpen Life on the computer (http://localhost:5055); the password still works there. Then turn the requirement off in Settings → Face ID.
A shared Instagram post lands in the InboxNothing readable was found (a hidden caption and unreadable slides). Copy the caption, open Capture, paste it and tap To lists. Use Settings → Use it on your iPhone → Test this token to check the Shortcut.
Garmin keeps emailing codesUpdate to this version: it signs in once and keeps tokens. Press Sync now, enter the one code, done.
Forgot the passwordStop Life, then in the project folder run .venv\Scripts\python -c "import sqlite3; c = sqlite3.connect('data/life.db'); c.execute('DELETE FROM kv WHERE k=?', ('pw',)); c.commit()" (on Mac/Linux use .venv/bin/python) and start Life: it asks you to choose a new password. Your data is untouched.
Port already in useSet LIFE_PORT=5056 in .env and restart (and re-run tailscale serve with the new port).
Something looks stale after an updateOn the phone close and reopen the app (it refreshes its cache on start).

Run the tests

.venv\Scripts\python tests\run_all.py          # everything (about 6 minutes)
.venv\Scripts\python tests\run_all.py --fast   # syntax, unit and backend tests (about 30 s)

They cover the backend, security rules, every page at desktop and phone size, Face ID with a virtual authenticator, touch gestures, offline mode and sync. A test also scans the repo for anything key-shaped.

Removing it

Stop Life and delete the project folder; your data went with it (data/). Before that, Settings → Your data → Export everything gives you a zip of all your records and notes.
