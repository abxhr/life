Set up

Run it

Windows: double-click run.bat. First run creates a virtual environment, installs the requirements and starts the server on http://127.0.0.1:5055. Open it and choose a password (8+ characters). Mac/Linux: ./run.sh.

To keep it running in the background, use a service wrapper such as NSSM: program .venv\Scripts\python.exe, arguments app.py, start directory = the project folder.

Reach it from your phone

Recommended: Tailscale on the computer and the phone, then tailscale serve --bg 5055 gives you a private HTTPS address only your devices can reach. Add LIFE_HTTPS=1 to .env so cookies are marked Secure. Never use tailscale funnel (that is public). A small VPS behind Caddy also works; the full steps are in SETUP-PHONE.md.

Add integrations in Settings

Everything is optional and fails softly into Settings → Data health. Keys you type in Settings are stored encrypted and applied immediately (no restart). A value in .env still works as a fallback.

IntegrationWhat forWhere
OpenAI keyAssistant, voice, share/enrichment (cheap models), Decisions API for entry rulesSettings → Voice & assistant
Anthropic keyOptional alternative for the assistantsame
Telegram botReminders, inbox capture, morning briefSettings → Reminders & Telegram

IMDb ratings★ on films and series (free dataset, ~7 MB, downloaded only when you press the button)Settings → Film & series ratings
OMDb keyOptional extra film detailsSettings → Voice & assistant

Set your passport country and where you live in Settings → You for the entry rules. Add the visas you hold in Travel → Documents (type "Visa").

Your data

  • One SQLite file, data/life.db. Settings → Your data: Export everything (JSON + Markdown), Download a backup (to the Files app on iPhone), Backup with key.
  • A nightly backup keeps 14 days in data/backups.
  • Back up data/fernet.key too. It encrypts passport numbers, health values, scans and the keys you entered. Lose it and those are unrecoverable, by design.

Run the tests

.venv\Scripts\python tests\run_all.py          # everything (about 6 minutes)
.venv\Scripts\python tests\run_all.py --fast   # syntax, unit and backend tests (about 30 s)

They cover the backend, security rules, every page at desktop and phone size, Face ID with a virtual authenticator, touch gestures, offline mode and sync. A test also scans the repo for anything key-shaped.
